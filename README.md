# João Vitor Pramio — Portfolio

Portfólio editorial responsivo desenvolvido com React e Vite.

## Executar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

Os textos, projetos, competências e links sociais ficam centralizados em `src/data/portfolio.js`. Imagens usadas pela interface ficam em `public/assets/`.
